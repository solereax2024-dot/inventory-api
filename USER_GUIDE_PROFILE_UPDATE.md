# User Guide - Profile Picture Update Feature

## How to Update Your Profile Picture

### Step 1: Open the Game
1. Sign in to your account
2. Start or join a Tetris game session

### Step 2: Access Profile Update
1. Look for the **"Update Profile Picture"** button in the mobile controls (at the bottom of the screen)
2. Click/tap the button

### Step 3: Upload Your Image
1. The profile update modal will appear
2. Click on the upload area or drag and drop an image
3. Select an image file from your device (JPG, PNG, WEBP)
4. The image will preview before uploading

### Step 4: Confirm and Upload
1. Review your selected image in the preview
2. Click **"Update Picture"** to upload
3. You'll see a loading indicator while uploading

### Step 5: Success
1. A success message will appear
2. The modal closes automatically
3. Your profile picture is now updated!

---

## Important Information

### Supported Image Types
- JPEG (.jpg, .jpeg)
- PNG (.png)
- WebP (.webp)
- Other standard image formats

### File Size Limit
- Maximum: **5 MB**
- If your file is larger, please compress it first using:
  - Online tools: TinyPNG, CompressJPEG
  - Desktop software: Photoshop, GIMP, Preview (Mac)
  - Mobile apps: image compression apps

### When You Can Update
- ✅ After registration and login
- ✅ During active gameplay sessions
- ✅ Anytime you're logged in

### What Happens to Your Old Picture
- Your new picture replaces the old one
- The change takes effect immediately
- No profile history is kept

## Troubleshooting

### Issue: Upload Button Not Showing
**Solution:**
- Make sure you're logged in
- The button appears in-game below your username
- Try refreshing the page if it still doesn't appear

### Issue: "File Too Large" Error
**Solution:**
- Your image is larger than 5MB
- Compress the image using an online tool
- Try a different image format (JPEG is usually smallest)

### Issue: "Invalid File Type" Error
**Solution:**
- Your file is not an image
- Make sure you're selecting an actual image file
- Try JPG or PNG format

### Issue: Upload Failed / Network Error
**Solution:**
- Check your internet connection
- Try again after 30 seconds
- If problem persists, try a different browser or device

### Issue: Modal Won't Close
**Solution:**
- Check if upload actually succeeded
- Try clicking the X button to close
- Refresh the page if stuck

## Tips & Best Practices

1. **Image Size**: Use images that are at least 256x256 pixels
2. **Format**: JPG format usually creates the smallest file size
3. **Aspect Ratio**: Square images (1:1) work best
4. **Quality**: 80-85% JPEG quality is usually sufficient
5. **Portrait**: For profile pictures, avoid images that are too wide

## FAQ

**Q: Can I change my profile picture multiple times?**
A: Yes! You can update it as many times as you want.

**Q: Will my old picture be visible to anyone?**
A: No, only your current profile picture is shown.

**Q: How long does it take to update?**
A: Usually less than 1 second on a good connection.

**Q: Can I delete my profile picture?**
A: You always need a profile picture to play. Upload a new one instead.

**Q: Is my profile picture stored securely?**
A: Yes, all profile images are stored securely on our servers.

**Q: Can I upload an image from my phone camera?**
A: Yes! Most devices allow you to take a photo and upload it directly.
